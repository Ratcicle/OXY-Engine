# Evidências de QA

Esta pasta guarda somente as evidências da versão atual. Os testes nativos e as medições gravam capturas e relatórios em `target/qa/` (fora do Git); defina `OXY_QA_DIR` para escolher outra pasta. Copie para cá apenas o que a documentação da versão referencia.

As capturas de versões anteriores continuam no histórico do repositório. Consulte a tag correspondente, por exemplo [`v0.3.0/qa/v0.3.0`](https://github.com/Ratcicle/OXY-Engine/tree/v0.3.0/qa/v0.3.0) ou, para todo o acervo até a 0.3.3.1, [`v0.3.3.1/qa`](https://github.com/Ratcicle/OXY-Engine/tree/v0.3.3.1/qa).
