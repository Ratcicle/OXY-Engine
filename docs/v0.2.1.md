- Janela **1440×900**, escala 100%, dimensões efetivas registradas em todas as fases. Uma tentativa inicial com tamanho variável foi descartada; a execução válida completa levou 567,09 s.

O arredondamento faz limpeza global de vértices e rejeita componentes soltos, inclusive não envolvidos. Esses problemas foram confirmados no código antes das correções.

## Reproduzir

```powershell
./scripts/benchmark-v021.ps1 -Label current
./scripts/compare-v021.ps1
```

Não executar builds ou outros testes durante a medição. `-Reference` executa a cópia imutável local após verificar seu hash. Em outra máquina, o commit-base mais o harness deste marco permite reconstruir a referência; não comparar tempos entre máquinas como se fossem a mesma execução.
